# Algorithm Labs

A collection of beginner programming and algorithm exercises created with Flowgorithm. The repository contains 53 editable `.fprg` flowchart files, mostly with Turkish names and prompts.

## Topics represented

- Loops, counters, and numeric series
- Conditions and input validation
- Arrays, minimum/maximum values, and ordering
- Number systems, digits, powers, and arithmetic
- Small calculation and guessing exercises

Representative examples include:

- [`fibonacci.fprg`](<Algorithms/fibonacci.fprg>) — Fibonacci sequence exercise
- [`10x10 çarpım tablosu.fprg`](<Algorithms/10x10 çarpım tablosu.fprg>) — multiplication table
- [`İkilik sistemden onluk sisteme geçiş.fprg`](<Algorithms/İkilik sistemden onluk sisteme geçiş.fprg>) — binary-to-decimal conversion
- [`En büyük ve En küçük sayı.fprg`](<Algorithms/En büyük ve En küçük sayı.fprg>) — minimum and maximum values
- [`Yazılan metni tersten yazan program.fprg`](<Algorithms/Yazılan metni tersten yazan program.fprg>) — reverse-text exercise

Browse the full set in [`Algorithms/`](Algorithms/).

## Open an exercise

1. Install Flowgorithm.
2. Open Flowgorithm and select a `.fprg` file from the `Algorithms` directory.
3. Inspect or run the flowchart from the application.

These files are educational exercises rather than a packaged application. Some use interactive input, and expected values or prompts may be in Turkish.
